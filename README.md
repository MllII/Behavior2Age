# Behavior2Age

**ML-модель для предсказания возрастной категории анонимных пользователей
по данным об их поведении в цифровой среде.**

Итоговый проект модуля 3: линейные модели машинного обучения.

## О проекте

Компания «Йети» управляет группой популярных интернет-сервисов и получает
значительную часть дохода от контекстной рекламы. Для эффективного
таргетинга и снижения рисков показа взрослой рекламы несовершеннолетним
нужна модель, которая по данным о поведении анонимного пользователя
определяет его возрастную категорию.

**Задача:** многоклассовая классификация (5 классов).
**Целевая переменная:** `age_category`:
- 0: младше 18,
- 1: 18–25,
- 2: 26–40,
- 3: 41–55,
- 4: 56+.

**Основная метрика:** `f1_macro`.
**Критерий успеха:** `f1_macro ≥ 0.75` на кросс-валидации и на тесте.

## Подход

1. **EDA:** анализ распределений, пропусков, дубликатов, выбросов; проверка
   гипотезы о связи поведения и возраста.
2. **Feature engineering:** доли активности по 20 категориям сайтов,
   доли по времени суток, среднее число сессий в день, наиболее активное
   время суток, доля активности в выходные.
3. **Предобработка:** `ColumnTransformer` с отдельными пайплайнами
   для числовых, номинальных, порядковых и бинарных признаков.
4. **Моделирование:** `DummyClassifier` (baseline), `LogisticRegression`,
   `SVC` с ядрами `linear`, `rbf`, `poly`; подбор гиперпараметров через
   `GridSearchCV`.
5. **Оценка:** `StratifiedKFold` (5 фолдов) со стратификацией,
   метрики `f1_macro`, `precision_macro`, `recall_macro`.
6. **Сохранение артефактов:** модель, пайплайн предобработки, функция
   `build_features`, метаданные.

## Результаты

**Лучшая модель:** `SVC` с ядром `rbf` (`C=1`, `gamma='scale'`).

| Метрика | Кросс-валидация | Тест |
|---|---|---|
| **f1_macro** | **0.8979 ± 0.0120** | **0.8860** |
| precision_macro | 0.9029 ± 0.0098 | 0.8891 |
| recall_macro | 0.8941 ± 0.0136 | 0.8833 |

**Цель достигнута с запасом ~0.14.** Модель рекомендована к внедрению.

### Сравнение моделей (f1_macro на CV)

| Модель | f1_macro |
|---|---|
| SVC (rbf) | **0.8979 ± 0.0120** |
| SVC (poly) | 0.8920 ± 0.0038 |
| SVC (linear) | 0.8249 ± 0.0057 |
| LogisticRegression | 0.8238 ± 0.0090 |
| DummyClassifier | 0.0930 ± 0.0001 |
